## Keys ที่ v3 ไม่ใช้ (โค้ดคงไว้ — v2 ยังอ่าน)

- `จำนวนข้อโต้แย้งที่ยัดเข้า prompt` — v3 ไม่มีแท็บ OBJ แยก (ความรู้รวม · เรียบเรียงสด) → ไม่ seed ใน v3 · โค้ด `numFromRaw` ยังอยู่เพื่อ v2
- `คำ_notify` / `คำ_notify_<step_id>` — v3 แทนด้วย `คำ_ธงสุขภาพ` (D-61.A)
- `ทักทายรายวัน`/`ข้อความแจ้งพัสดุ`/`ขนส่ง_เริ่มต้น` — ใช้ต่อทั้งสองโหมด (seed แล้ว)

## Keys ใหม่ v3 (D-61.A)

`คำ_ธงสุขภาพ` · `คำรับรอง_ต้องห้าม` · `ข้อความ_แจ้งแอดมิน_notify` — seed แล้วพร้อมค่า default

## สิ่งที่เจ้าของต้องกรอกจริงก่อน cutover (seed ใส่ placeholder ไว้)

- `เลขที่บัญชี` / `ชื่อบัญชี` / `ธนาคาร` — 🔴 ยังเป็น `(กรอก...จริง)` — transfer guard จะบล็อกข้อความโอนจนกว่ากรอก
- `คำต้องห้าม_โฆษณา` — seed ค่าตั้งต้นทั่วไป เจ้าของเติมตามที่เคยใช้ใน v2
- รูปสินค้า (URL) ใน CSV_Products — ว่างอยู่
- แท็บ **ความรู้** — มีแถวตัวอย่าง K001 เดียว (draft) · เนื้อจริงเติมผ่านผู้ช่วยเทรน v3 (เฟส D โหมดสัมภาษณ์)
